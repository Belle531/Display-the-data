# Async/Await Fetch Assignment

## Objective
Build a small web app that uses an **async/await** function to fetch data from an API and display the result in a styled card.

## Instructions

### 1. Setup
- Open `index.html` in your browser to preview the layout.
- The card and button are styled with basic CSS in `style.css`.

### 2. Your Task
Open the `script.js` file. Follow the instructions in the comments to:
- Add an event listener to the button
- Write an async function that fetches a message from this API:  
  `https://baconipsum.com/api/?type=meat-and-filler&paras=1`
- Display the returned message inside the paragraph with `id="messageText"`
- Handle errors gracefully

### 3. Bonus
- Try styling the button or card with your own creative ideas.
- Add a loading message while the fetch is running.
